# 🛍️ E-commerce Recommendation System

A machine learning project that recommends products to customers using **Item-Based Collaborative Filtering** and **Popularity-Based Recommendation**.

## 📌 Project Overview

E-commerce platforms offer many products, making it difficult for customers to discover relevant items. This project uses customer-product interaction and rating data to generate personalized product recommendations and provide a popularity-based alternative.

The application is built with Python and Streamlit, with a modular machine learning pipeline for data preprocessing, model training, and evaluation.

## 🎯 Objectives

- Recommend relevant products based on customer preferences.
- Build a popularity-based recommendation baseline.
- Implement item-based collaborative filtering.
- Evaluate recommendation performance using appropriate metrics.
- Develop an interactive Streamlit application.
- Package the application using Docker.

## 📊 Dataset

The dataset contains **20,000 customer-product interactions**.

| Attribute | Details |
|---|---|
| Customers | 1,000 |
| Products | 63 |
| Product categories | 5 |
| Interaction records | 20,000 |
| Average rating | 3.90 out of 5 |

**Features include:**
- `customer_id`
- `product_id`
- `product_name`
- `category`
- `rating`
- `timestamp`

## ⚙️ Recommendation Approaches

### 1. Popularity-Based Recommendation

Recommends popular products based on interaction and rating information. It provides a baseline and a fallback when personalized recommendations are unavailable.

### 2. Item-Based Collaborative Filtering

Uses patterns in customer-product interactions to identify products related to those a customer has rated. It generates recommendations based on item similarity and excludes products the customer has already rated.

## 📈 Model Evaluation

The models are evaluated using rating prediction metrics and ranking metrics.

- **MAE:** Mean Absolute Error
- **RMSE:** Root Mean Squared Error
- **Precision@5:** Proportion of the top five recommendations that are relevant.
- **Recall@5:** Proportion of relevant products retrieved in the top five recommendations.

The project includes a model evaluation pipeline that saves results for comparison.

## 🚀 Getting Started

### Prerequisites

- Python 3.12 or a compatible Python environment
- Git
- Docker (optional)

### 1. Clone the repository

```bash
git clone https://github.com/arpitakumaripadhy-bot/ecommerce-recommendation-system.git
cd ecommerce-recommendation-system
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run exploratory data analysis

```bash
python run_eda.py
```

### 5. Train and evaluate the recommendation models

```bash
python train_pipeline.py
```

### 6. Launch the Streamlit application

```bash
python -m streamlit run streamlit_app.py
```

Open the local URL displayed in your terminal, usually `http://localhost:8501`.

**Note:** The raw dataset must be present at `artifacts/data/raw/ecommerce_recommendation_interactions.csv` before running the pipeline. Model artifacts, processed data, and generated visuals may be created locally during execution.

## 🐳 Run with Docker

Build the Docker image:

```bash
docker build -t ecommerce-recommendation-system .
```

Run the container:

```bash
docker run --rm -p 8501:8501 ecommerce-recommendation-system
```

Open `http://localhost:8501` in your browser.
